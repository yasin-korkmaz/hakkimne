# HakkımNe?

Türk İş Hukuku kapsamında kıdem ve ihbar tazminatını adım adım hesaplayan, tamamen tarayıcı taraflı çalışan açık kaynaklı bir hesaplayıcı.

> **Durum: geliştirme aşamasında, oranlar henüz doğrulanmadı.**

---

## Proje Dosyaları

| Dosya | Açıklama |
|---|---|
| `AGENTS.md` | Ajan kuralları ve teknoloji yığını |
| `PRD.md` | Ürün gereksinim dokümanı (Faz 1 - MVP) |
| `DECISIONS.md` | Mimari ve hukuki karar günlüğü |
| `MIMARI.md` | Teknik mimari belgeleri |
| `ILK_GOREVLER.md` | Proje sahibi doğrulama görevleri |
| `src/config/rates.json` | Kıdem tavanı, damga vergisi ve ihbar kademeleri |
| `tests/fixtures/rates.test.json` | Test fixture (doğrulanmış oranlar) |
